# Zed Terminal Release Notes

This file records major standalone `zed_terminal` milestones and release-capable checkpoints.

## 2026-06-04 - Default Profile Management

Status: default-profile-management checkpoint

- Added `zed-terminal --set-default-profile <name>` to update the default startup profile in `terminal.json` without opening a terminal window.
- Added Shell > Set Default Profile menu entries for visible configured profiles.
- Added the parameterized `zed_terminal::SetDefaultStartupProfile` action so user keymaps can set the default profile directly.
- Reused the existing `TerminalStartupConfig` validation path before writing, so blank names, missing profiles, and invalid resulting layouts are rejected.
- Used `settings_json::replace_value_in_json_text` to update only the top-level `default_profile` field and preserve surrounding JSONC comments/formatting where possible.
- Kept hidden profiles out of the menu while still allowing direct CLI/keymap selection.
- Kept the change isolated to the standalone app and did not touch terminal rendering, input, or `terminal_view`.
