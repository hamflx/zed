# Zed Terminal Release Notes

This file records major standalone `zed_terminal` milestones and release-capable checkpoints.

## 2026-06-06 - Profile Slot Window Action

Status: profile-slot-window-action checkpoint

- Added `zed_terminal::NewTerminalWindowWithProfileSlot`, an object-input action that opens a new standalone terminal window from the Nth visible startup profile in the current `terminal.json` profile summary ordering.
- Reused the same 1-based visible profile slot resolver as profile slot tabs and splits, so hidden profiles are skipped and missing slots leave the current window unchanged after logging a warning.
- Reused the existing profile-window launch path: the selected profile becomes a one-tab `LaunchOptions`, configured profile tabs are not replayed, split placement is cleared, and window creation still flows through `open_terminal_window`.
- Kept this as a user-keymap and action-catalog surface without adding bundled default keybindings, completing the profile slot action family for tab, window, and split targets without introducing shortcut conflicts.
- Extended Rust coverage plus package/release gates to validate the new action schema, parser behavior, action catalog metadata, action descriptions, and profile-window launch semantics.
- Kept this as keymap/action/product-surface work only; no renderer, PTY setup, input handling, shell/task creation, startup visual styling, or terminal visual styling was changed.

## 2026-06-06 - Profile Slot Keybindings

Status: profile-slot-keybindings checkpoint

- Added `zed_terminal::NewTerminalTabWithProfileSlot`, an object-input action that opens the Nth visible startup profile from the current `terminal.json` profile summary ordering.
- Bound `ctrl-shift-1` through `ctrl-shift-9` to visible startup profile slots 1 through 9, matching Windows Terminal's new-tab-by-profile-slot workflow without hardcoding profile names.
- Removed the conflicting bundled `ctrl-shift-5` split-right default binding; split-right remains available through Shell/Paned menus, the command palette, and user keymaps, while split down remains available through `alt-shift-plus` and `alt-shift-minus`.
- Hidden profiles are skipped by profile slot keybindings but remain directly invokable through explicit profile actions and restorable through Shell > Show Profile.
- Extended Rust coverage plus package/release gates to validate the new action schema, default keymap references, action catalog metadata, action descriptions, binding descriptions, and printed default keymap.
