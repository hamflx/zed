# Zed Terminal Release Notes

This file records major standalone `zed_terminal` milestones and release-capable checkpoints.

## 2026-06-04 - Startup Command Environment

Status: startup-env checkpoint

- Added `env` maps to root-level `terminal.json`, named startup profiles, and individual startup tabs.
- Passed startup env through `task::SpawnInTerminal.env` for command-backed terminal launches, preserving Zed's existing task-backed terminal creation path.
- Made root/profile env the inherited default for configured startup commands, CLI `-- <command>` overrides, configured command tabs, and CLI `--new-tab-command` / `--tab-command` tabs.
- Allowed tab-level env to override inherited root/profile keys for configured command-backed tabs.
- Kept shell-only tabs on the existing `Project::create_terminal_shell` path; they do not receive startup env overrides.
- Rejected tab-level env on configured shell-only tabs so unsupported env does not fail silently.
- Updated the generated `terminal.json` template with an empty `env` map and documented that env applies only to command-backed startup tabs.

## 2026-06-04 - Startup Profiles

Status: startup-profiles checkpoint

- Added parser coverage for default profiles, CLI-selected profiles, CLI overrides on selected profiles, missing profile diagnostics, and `--paths --profile` behavior.

## 2026-06-04 - Startup Config Layout

Status: startup-config checkpoint

- Added a standalone `terminal.json` startup layout file under the active terminal config directory.
- Kept startup layout separate from Zed's normal `settings.json` so renderer, theme, font, and terminal settings remain owned by the existing Zed SettingsStore.
- Created `terminal.json` on first app startup and added a menu action for opening it.
- Reported `startup_config_file` from `zed-terminal --paths`.
- Supported configured `working_directory`, `command`, and `tabs`, including per-tab command and working directory combinations.
- Parsed configured command strings with the same `shlex` path used by `--new-tab-command`.
- Parsed `terminal.json` with Zed's JSON-with-comments parser and rejected unknown fields so misspelled startup keys fail early.
- Added `--no-startup-config` for clean one-off launches that ignore the configured startup layout.
- Kept CLI precedence explicit: CLI initial directory and command override the configured initial tab, while CLI `--new-tab` and `--new-tab-command` entries append after configured tabs.
