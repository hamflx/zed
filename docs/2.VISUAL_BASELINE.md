# Zed Terminal Visual Baseline

This document defines the trusted visual baseline policy for the standalone
`zed-terminal` release gate.

## Baseline Asset

- Default Windows baseline:
  - `crates/zed_terminal/test_fixtures/visual/zed-terminal-default-windows.png`
- Startup split-pane Windows baseline:
  - `crates/zed_terminal/test_fixtures/visual/zed-terminal-split-windows.png`
- Baselines are captured from the real `target\debug\zed-terminal.exe` desktop app by
  `script\zed-terminal-visual-smoke.ps1`. The split-pane baseline is captured with
  `-VerifySplitPane`.
- Baselines remain full-window screenshots for review, and each smoke run also writes a
  full-client screenshot for diagnostics.
- Release comparison crops the stable client content area from both the fresh screenshot
  and the baseline before measuring pixel drift. The comparison excludes the top Windows
  capture-boundary strip while still covering terminal/tab rendering.
- The smoke probe text is intentionally stable. It must not include run-specific paths,
  timestamps, process ids, or temporary file names.

## Release Policy

- `script\zed-terminal-release-check.ps1` uses both default baselines automatically when
  visual smoke and split visual smoke are enabled.
- `-VisualBaselineImage <png>` overrides only the default single-pane baseline.
- `-SplitVisualBaselineImage <png>` overrides only the startup split-pane baseline.
- The default pixel policy is:
  - `BaselinePixelTolerance = 4`
  - `MaxBaselineDifferentPixelRatio = 0.02`
  - `MaxBaselineAverageChannelDelta = 2.0`
- A default release run must keep the baseline comparison enabled.
- `-SkipVisualBaseline` is a local debugging escape hatch only. Do not use it for release
  sign-off. It skips both default and split-pane baseline comparison.
- `-SkipVisualSmoke` still skips the whole desktop visual smoke path and therefore also
  skips baseline comparison.
- `-SkipSplitVisualSmoke` skips startup split-pane smoke and therefore also skips the
  split-pane baseline comparison.

## Updating The Baseline

Update the baseline only after a deliberate visual review confirms the change is intended.

1. Build `zed-terminal`.
2. Run:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File script\zed-terminal-visual-smoke.ps1 -UpdateBaselineImage crates\zed_terminal\test_fixtures\visual\zed-terminal-default-windows.png
```

3. To update the split-pane baseline, run:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File script\zed-terminal-visual-smoke.ps1 -VerifySplitPane -UpdateBaselineImage crates\zed_terminal\test_fixtures\visual\zed-terminal-split-windows.png
```

4. Visually inspect each updated PNG.
   The full-window PNG is useful for human review; the release gate compares the stable
   client-content crop generated in each smoke run.
5. Run:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File script\zed-terminal-release-check.ps1
```

6. Record the reason for the baseline update in `docs/1.RELEASE.md`.

Do not update the baseline to hide an unexplained rendering difference.
